# 🚀 AI Search Visibility Analyzer

AI Search Visibility Analyzer is a modern AI-powered analytics platform that monitors how brands appear inside responses generated by Large Language Models (LLMs) such as:

* ChatGPT
* Gemini
* Claude
* Perplexity
* Groq / Llama Models

The system analyzes brand visibility, rankings, sentiment, and share-of-voice across AI-generated responses and visualizes insights through an interactive dashboard.

#  How It Works

1. User enters a search query
2. Query is sent to multiple LLM APIs
3. Responses are collected
4. Brand mentions are analyzed
5. Rankings and sentiment are calculated
6. Share-of-voice is visualized
